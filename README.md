## 📋 À propos du projet

Ce projet est mon portfolio. Il a été conçu pour être une vitrine moderne et performante de mon parcours de développeur. L'objectif était de créer une expérience utilisateur fluide et agréable grâce à des animations subtiles et un design épuré.

Le site est entièrement **responsive** et gère plusieurs langues grâce à `vue-i18n`.

### ✨ Fonctionnalités

* **Framework Moderne** : Construit avec **Vue 3** (Composition API) et **Vite** pour un développement rapide et performant.
* **Typage Statique** : Utilisation de **TypeScript** pour un code plus robuste et maintenable.
* **Animations Fluides** : Intégration de **GSAP** (GreenSock Animation Platform) pour des animations complexes et optimisées.
* **Internationalisation** : Support multilingue (français/anglais) avec `vue-i18n`.
* **Design Responsive** : Une interface qui s'adapte parfaitement à toutes les tailles d'écrans, du mobile au bureau.

## 🚀 Démarrage

Suivez ces étapes pour lancer une copie du projet sur votre machine locale.

### Prérequis

Assurez-vous d'avoir [Node.js](https://nodejs.org/) (version 16 ou supérieure) installé.

### Installation

1.  Clonez le dépôt :
    ```sh
    git clone https://github.com/romainb82/portfolio.git
    ```
2.  Naviguez dans le dossier du projet :
    ```sh
    cd portfolio
    ```
3.  Installez les dépendances NPM :
    ```sh
    npm install
    ```

## 🛠️ Scripts disponibles

Dans le répertoire du projet, vous pouvez exécuter les commandes suivantes :

### `npm run dev`

Lance l'application en mode développement avec le rechargement à chaud (hot-reload).
Ouvrez [http://localhost:5173](http://localhost:5173) (ou le port indiqué) pour la voir dans votre navigateur.

### `npm run build`

Compile et minifie l'application pour la production. Les fichiers optimisés sont générés dans le dossier `dist/`.

### `npm run preview`

Lance un serveur local pour prévisualiser le build de production.

### `npm run type-check`

Vérifie les types TypeScript dans l'ensemble du projet sans générer de build.
