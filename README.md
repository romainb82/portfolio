# Full Stack Developer Portfolio

## Description

This project is a portfolio website built to showcase the skills and projects of a full-stack developer. It's designed to be visually appealing and informative, providing a comprehensive overview of the developer's capabilities and experience.

## Technologies Used

*   **Frontend:**
    *   Vue 3: A progressive JavaScript framework used for building the user interface.
    *   TypeScript: A superset of JavaScript that adds static typing for improved code quality and maintainability.
    *   Vite: A build tool that provides fast development and build times.
*   **Other:**
    *   HTML5: For structuring the content of the web pages.
    *   CSS3: For styling and layout.
